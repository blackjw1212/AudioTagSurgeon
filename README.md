# AudioTagSurgeon — 音訊標籤自動化外科手術工具

從**雜亂的檔名**精準切分「演出者」與「歌曲名稱」，做簡轉繁（台灣正體 s2twp）與去雜訊，
**先預覽、確認後才寫入**音訊內建標籤並重命名實體檔案。只動該動的，不破壞音訊與其他元數據。

## 安裝

```bash
pip install -r requirements.txt
```

> `tkinter` 為 Python 內建，無需另裝。`tkinterdnd2` 提供拖放支援（缺少時仍可用「選擇資料夾」按鈕）。

## 使用

```bash
python app.py
```

1. 點「選擇資料夾」（重新載入）、「加入檔案」（附加個別 .mp3/.flac，自動去重），
   或直接把**資料夾或音訊檔**拖入視窗。
2. 工具於對照表列出
   【修改勾選 / 原始檔名 / 演出者 / 歌曲名稱 / 預覽 (演出者 - 歌曲名稱) / 狀態】。
   （預覽欄不顯示副檔名；實際重命名時仍保留真實副檔名。）
3. 點「修改」欄可勾選/取消個別檔案；點「修改」**欄位標題**可全選/全不選；
   取消勾選的檔**完全不會被動**。
4. 確認無誤後點「**確認修改**」——在此之前**不會更動任何硬碟檔案**。

## 轉換邏輯

- **檔名優先、標籤交叉校驗**：檔名切成兩半後與內嵌標籤比對——
  - 正序吻合 → 以**檔名**內容為準（檔名寫 `L8R&阿林` 就維持 `&`，不被標籤蓋掉）；
  - 反序吻合 → 檔名是「歌名 - 演出者」順序，自動對調校正（`Zombie - The Cranberries` → 演出者 `The Cranberries`）；
  - 皆不吻合 → 檔名切分不可信（如 `A-Lin` 被裸連字號切壞），改用標籤；
  - 檔名無分隔符 → 用標籤；標籤也缺 → 標示「無法解析」。
- 檔名切分：優先「空白-空白」形式（`A-Lin - 歌名` 不會切壞），無則取第一個 `-`（含全形 `－—–`）。
- 簡轉繁：OpenCC `s2twp`（台灣正體與慣用語）。
- 去雜訊：前導曲目編號（`01.`）、Live/版本標記（`+(Live)`、`_修正版`…）、
  音質/來源標記（`320K`、`HQ`、`官方版`…）、標籤垃圾色碼（`#0000FF`）、多餘空格與孤立符號。
- 範例：`蔡依林-说爱你+(Live).mp3` → `蔡依林 - 說愛你.mp3`
- 找不到分隔符的檔名標示為「無法解析」，**不修改**。

## 安全保證

- 未點「確認修改」前，零硬碟寫入。
- MP3 僅設 EasyID3 的 `artist` / `title`；FLAC 僅設 Vorbis Comment 的 `artist` / `title`。
- 重命名目標已存在時**跳過不覆蓋**（標示「✗ 衝突」）。

## 測試

```bash
python -m pytest tests/
# 或
python -m unittest tests.test_cleaner
```

## 檔案結構

| 檔案 | 職責 |
|------|------|
| `cleaner.py` | 純函式：切分 + 簡轉繁 + 去雜訊 + 安全檔名 |
| `tagger.py`  | 寫入內建標籤 + 實體重命名（唯一動硬碟） |
| `app.py`     | Tkinter GUI：掃描、預覽表、確認、拖放 |
| `tests/`     | cleaner 單元測試 |
